Entry for the make.fun bounty
[One Word, One Username, One Reward](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae).

The program writes our own make.fun username — one word and nothing else —
to `/output/entry.txt`.

Entry: `brayen-suryanto` (15 characters, one word, no explanation, no links,
no pitch).

Run it with Node:

```sh
node main.ts
```

Set `OUTPUT_DIR` to write the entry somewhere else (the harness runs it with
its own output directory).
